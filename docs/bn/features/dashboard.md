# ড্যাশবোর্ড

Somtum-এ আপনার মেমরি ভিজ্যুয়ালি ব্রাউজ এবং পরিচালনার জন্য একটি স্থানীয় ওয়েব ড্যাশবোর্ড রয়েছে।

## ড্যাশবোর্ড শুরু করা

```bash
somtum serve
# http://localhost:3000 খোলে
```

বন্ধ করতে `Ctrl-C` চাপুন।

## ফ্ল্যাগ

| ফ্ল্যাগ | ডিফল্ট | বিবরণ |
| --- | --- | --- |
| `--port <n>` | 3000 | কাস্টম পোর্টে শুনুন |
| `--no-open` | — | ব্রাউজার না খুলে সার্ভার শুরু করুন |

```bash
somtum serve --port 3001
somtum serve --no-open
```

## ভিউ

### মেমরি ব্রাউজার

সমস্ত ক্যাপচার করা পর্যবেক্ষণের একটি অনুসন্ধানযোগ্য, ফিল্টারযোগ্য তালিকা। আপনি করতে পারেন:

- লাইভে BM25, হাইব্রিড এবং এমবেডিং রিট্রিভাল কৌশলের মধ্যে পরিবর্তন করুন
- ধরন অনুযায়ী ফিল্টার করুন (`decision`, `bugfix`, `learning` ইত্যাদি)
- যেকোনো মেমরিতে ক্লিক করুন তার পূর্ণ বডি, সংশ্লিষ্ট ফাইল এবং ট্যাগ দেখতে

### নলেজ গ্রাফ

নোডগুলি মেমরি; এজগুলি এমন মেমরি সংযুক্ত করে যা ফাইল বা ট্যাগ শেয়ার করে। বিস্তারিত প্যানেলে খুলতে একটি নোডে ক্লিক করুন। সম্পর্কিত সিদ্ধান্ত এবং শিক্ষার ক্লাস্টার দেখার জন্য দরকারী।

### অ্যানালিটিক্স

- ধরন ব্রেকডাউন (কতটি সিদ্ধান্ত বনাম bugfix বনাম শিক্ষা)
- সময়ের সাথে ক্যাশ হিট রেট
- রিট্রিভাল কৌশল ব্যবহার
- সর্বোচ্চ-উল্লেখিত ফাইল

### ফর্গেট বাটন

ব্রাউজার থেকে সরাসরি যেকোনো মেমরি soft-delete করুন। মুছে ফেলা মেমরি পুনরুদ্ধার করা যাবে:

```bash
somtum export --include-deleted
```

অথবা স্থায়ীভাবে মুছুন:

```bash
somtum purge --older-than 0d
```
