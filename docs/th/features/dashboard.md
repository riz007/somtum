# แดชบอร์ด

Somtum มีแดชบอร์ดเว็บในเครื่องสำหรับเรียกดูและจัดการความทรงจำของคุณแบบวิชวล

## การเริ่มต้นแดชบอร์ด

```bash
somtum serve
# เปิด http://localhost:3000
```

กด `Ctrl-C` เพื่อหยุด

## Flag

| Flag | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- |
| `--port <n>` | 3000 | รับฟังบนพอร์ตที่กำหนดเอง |
| `--no-open` | — | เริ่ม server โดยไม่เปิดเบราว์เซอร์ |

```bash
somtum serve --port 3001
somtum serve --no-open
```

## มุมมอง

### ตัวค้นหาความทรงจำ

รายการข้อสังเกตที่บันทึกทั้งหมดที่ค้นหาและกรองได้ คุณสามารถ:

- สลับระหว่างกลยุทธ์การดึงข้อมูล BM25, hybrid และ embeddings แบบ live
- กรองตามประเภท (`decision`, `bugfix`, `learning` ฯลฯ)
- คลิกความทรงจำใดก็ได้เพื่อดูเนื้อหาเต็ม ไฟล์ที่เกี่ยวข้อง และแท็ก

### กราฟความรู้

โหนดคือความทรงจำ ขอบเชื่อมความทรงจำที่แชร์ไฟล์หรือแท็ก คลิกโหนดเพื่อเปิดในแผงรายละเอียด มีประโยชน์สำหรับดูกลุ่มของการตัดสินใจและข้อเรียนรู้ที่เกี่ยวข้อง

### การวิเคราะห์

- การแบ่งตามประเภท (จำนวน decisions กับ bugfixes กับ learnings)
- อัตราการโดน cache เมื่อเวลาผ่านไป
- การใช้งานกลยุทธ์การดึงข้อมูล
- ไฟล์ที่ถูกอ้างอิงมากที่สุด

### ปุ่มลืม

ลบความทรงจำแบบ soft-delete โดยตรงจากเบราว์เซอร์ ความทรงจำที่ลบแล้วสามารถกู้คืนได้ด้วย:

```bash
somtum export --include-deleted
```

หรือลบถาวรด้วย:

```bash
somtum purge --older-than 0d
```
